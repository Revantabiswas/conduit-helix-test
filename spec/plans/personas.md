# Personas

## Developer / Operator (primary)
- **Role**: Builds, deploys or debugs the Conduit backend.
- **Need**: Confirm which backend version is running with one request, without shell access or reading logs.

- **Role**: Automated consumers that may read the version later.
- **Need**: A stable, public JSON contract for name and version. Not a driver for this story.
- **Stories**: 1.1 (indirect)
